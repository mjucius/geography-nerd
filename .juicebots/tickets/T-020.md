# T-020: No same-name pairs in a question

## Acceptance
- No question pairs two cities whose displayed names are the same when case and accents are ignored; for example London, UK and London, Canada never appear together (brief 10, Decision 8).
- A test checks every valid pair of every level, and quizzes at every level.
- Every level still has at least 200 valid pairs.
- `npm test` and `npm run lint` pass.

## Plan
Files: `web/src/services/quizService.ts`, tests in `web/src/services/__tests__/levels.test.ts` and `quizService.test.ts`.
Approach: `validPairs` skips a pair when `sameName(a, b)`: both cities' displayed names (the existing `formatCityName`, so Washington shows as "Washington D.C.") are compared after Unicode NFD normalization, removing combining marks and lowercasing. One small helper in `quizService.ts`, applied where `asked > 0` is checked. The check sits in `validPairs` so the cache, the 200-pair counts and every quiz agree, and nothing else changes. In the shipped data this removes pairs of London (GB, CA), Cordoba (AR, ES), Cartagena (CO, ES), Hamilton (CA, NZ) and Newcastle (AU, ZA); no other same-name groups exist after T-019 (I checked the SQL: 5 groups across countries).
Tests: (levels.test.ts) for every level, no valid pair has the same normalized displayed name (computed in the test with its own normalization, not the helper); the London GB / London CA pair is not in any level's valid pairs even though both cities are in the pool of level 10 (checked: they are); synthetic pools prove the rule: "Córdoba" vs "Cordoba", "LONDON" vs "London" are dropped while "Cordoba" vs "Cartagena" stays (this shows accent and case folding separately); every level still has 200+ pairs (existing test). (quizService.test.ts) in the existing 50-quiz loop, no question's two displayed city names (`questionTextParts`) match ignoring case and accents.
Prove tests can fail on a copy outside the repo: remove the name check (London test, synthetic and quiz tests red); remove accent folding (accent synthetic case red); remove lowercasing (case synthetic case red); compare raw `name` instead of the displayed name with a synthetic Washington/"Washington D.C." pair (display test red).
Run `npm test`, `npm run lint`, `npx tsc -b` and `npm run build:web` in the foreground and read exit status.

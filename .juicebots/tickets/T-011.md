# T-011: Missing test: reveal and results show the same east-west number (brief 21)

## Problem
`QuestionCard.test.tsx` asserts only the North km string, and `ScoreScreen.test.tsx` asserts only `'km /'`. No component test checks the East/West km value, so nothing proves the reveal and the results screen show the latitude-scaled east-west distance, or that they agree (brief 21). Dropping `getDistanceInfo` from either component's `ew` line, or using raw degrees there, would pass `npm test`.

## Acceptance
- A test covers the East/West line on the reveal (`QuestionCard`) for a longitudinal question at a non-zero latitude, asserting the cos(mean latitude)-scaled km and mi string.
- A test covers the same line on the opened results row (`ScoreScreen`) for the same question and asserts the identical string.
- Each test fails if the cos factor is removed in `distance.ts`.

## Plan
Test-only; no app code changes.
- `web/src/test-fixtures.ts`: add `longitudinalQuestion` (Oslo 59.91N 10.75E vs Moscow 55.76N 37.62E, answer West). Mean lat 57.8, so the cos factor is ~0.53 and the scaled value differs a lot from raw degrees.
- `QuestionCard.test.tsx`: reveal with that question asserts the literal text `West by 1,592 km / 989 mi` (hand-computed: 26.87 x 111.32 x cos 57.835 = 1592.4; unscaled would be 2,991).
- `ScoreScreen.test.tsx`: pass `questions` with that question, open row 1, assert the same literal text.
- The literal is the same string in both tests, so they prove agreement as well as the scaling.
- Verify: `npm test`; then drop the cos factor in `distance.ts` on an outside copy and confirm both new tests fail.

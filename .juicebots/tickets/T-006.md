# T-006: Compact results screen

## Acceptance
- Score summary plus one compact row per question: tick/cross, the question, your answer, and the correct answer if missed.
- Map and distance (km + miles, no degrees) open per row on tap; collapsed by default.
- All ten rows fit in about two mobile screens when collapsed (checked at 390x844).
- Tests for collapsed/expand behaviour; `npm test` passes.

- Cards are never nested more than one level deep on this screen.

## Plan
Files:
- `web/src/components/ScoreScreen.tsx` (rewrite of the markup; props, scoring, level logic and copy unchanged):
  - **Summary card** (one card, no nested cards): "Level N: Name" as plain text, the score ("7 / 10", display font, large), a thin progress bar, the existing score message as the heading, and the existing level actions (next level unlocked / get 8 to unlock / top route) as a hairline-separated block with buttons, with no tinted bordered sub-cards. The dark inverted score box, the "%" figure, "Route complete" and the Correct/Missed tiles go. Same button labels and `onStartLevel` calls.
  - **Review card**: heading "Route Review" and a one-line hint, then a `<ul>` of rows divided by hairlines (no bordered card per row). Each row is a native `<details>`: the collapsed `<summary>` is one compact row with a tick/cross, the question text, "Your answer: X" and, if missed, "Correct: Y", plus a chevron. At least 56px tall, whole row tappable, `focus-visible` outline. Ten collapsed rows are about 640px, so with the summary card they fit in about two 390x844 screens.
  - **Expanded row**: the distance as two plain lines from the shared `getDistanceInfo`/`formatDistance` (km + mi, no degrees; this removes the third copy of the maths and the `°` text) and the `MapView`.
  - **Map only mounts when the row is open** (small `RouteRow` component with an `onToggle` state). Today all ten maps render inside closed `<details>`, so Leaflet initialises at zero size (wrongly fitted bounds) and ten tile sets are set up per results screen. This also means fewer requests to the OSM tile servers.
  - All hex replaced with tokens; buttons: teal primary, line-bordered secondary, `disabled:opacity-60`, 48px tall.
- `QuizContainer.tsx`: add `quizCompleted` to the scroll-to-top effect's deps, so the results open at the top (submitQuiz does not change the question index; review recommendation), plus one assertion in `QuizContainer.test.tsx`. No change to `useQuiz`.
- Tests: new `web/src/components/__tests__/ScoreScreen.test.tsx` (uses `test-fixtures.ts`): 10 rows render collapsed (no `open`, and no map or "km" text in the DOM); a missed row shows "Correct: X" and a correct row does not; clicking a row opens it, shows "km" and "mi" and no "°" and mounts the map (`.leaflet-container`); closing it unmounts the map; the score "7 / 10" and the level actions still call `onStartLevel` with the right levels (stay, next, and Level 10 -> 9); "Back to Home" calls `onRetakeHome`.

Test: `npm test`, `npm run build`, `npm run lint` in the foreground; hex grep over ScoreScreen.tsx is empty.

# T-004: Restyle question card: one progress, scroll to top

## Acceptance
- Progress appears once on the question card (bar plus "3 of 10" or similar); the 0%, 1/10 and duplicate text are gone.
- The quiz always opens scrolled to the top, with the card fully visible below the header on mobile.
- Answer buttons are plain, large tap targets (>=44px) using tokens.
- Quiz behaviour unchanged; tests added/updated; `npm test` passes.

- Cards are never nested more than one level deep on this screen.

## Plan
Scope note: `QuestionCard.tsx` holds both the question and the answer reveal. T-004 restyles the question half (header/progress, question text, answer buttons). T-005 owns the reveal block below (`lastAnswer && ...`: result, distance, map, Next button) and its hex colours. Until T-005 that block is left as is. Quiz logic is untouched.

Files:
- `web/src/components/QuestionCard.tsx` (question half only):
  - Progress once: one line "Question 3 of 10" plus the bar (`role="progressbar"` with `aria-valuenow/min/max`, `aria-label`). Remove the big "%" text, the "n/10" chip and the redundant pill borders. "Level N" stays as plain small text (it is meaningful), and "Challenge" stays as a small amber-filled label, both sentence-case with no tracked uppercase.
  - Nesting: outer card (surface, hairline border, `rounded-card`, no heavy shadow) is the only card. The question text sits directly on it, with no bordered box inside it, and city names (`QuestionText.tsx`) become bold teal text instead of boxed chips. Per-direction accent colours (#8a4f2b, #7a5a8a etc.) are dropped, so all options share ink/teal tokens.
  - Answer buttons: min height 72px (>=44px), `focus-visible` teal outline, selected correct = teal border, wrong = clay border (tokens). Same props and `onAnswer` behaviour, same disabled logic.
  - Hex in the question half moves to tokens.

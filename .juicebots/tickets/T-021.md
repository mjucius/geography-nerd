# T-021: Script that flags sub-city entries from Wikidata classes

## Acceptance
- A script reads the Wikidata instance-of classes of every committed QID and writes a committed report `data/subcity-flags.json` with each city's class labels and whether it is flagged; a city is flagged when all of its classes are sub-city or administrative-area classes (brief 11, how the list is built).
- The report flags every example named in the brief (Eixample, Hamburg-Nord, Sector 4, Gustavo A. Madero, South Boston, Tuggeranong Administrative District) and does not flag Brampton, Yokohama, Giza or Quezon City; a test on the committed report checks this.
- The game does not read the report and makes no network call.
- `npm test` and `npm run lint` pass.

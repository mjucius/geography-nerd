# T-002: Design tokens, self-hosted fonts, plain background

## Acceptance
- Colours, radii and fonts are defined once as Tailwind v4 `@theme` tokens in `web/src/index.css`; `web/tailwind.config.js` is deleted.
- Fraunces (headings) and Inter (body) are self-hosted via bundled packages; no request to Google Fonts or any font CDN.
- One page background, no graph-paper grid. No dark mode. Logo unchanged.
- `npm test` and `npm run build` pass.

## Plan
Current state: `index.css` hardcodes colours and a grid-paper body background; `tailwind.config.js` is dead (Tailwind v4 never loads it); Inter is named but never loaded; components hold 28 distinct hex colours (to be migrated in T-003 to T-006, so this ticket defines the tokens and they keep rendering as today).

Files:
- `web/package.json` (+ lockfile): add `@fontsource-variable/inter` and `@fontsource-variable/fraunces` as dependencies via `npm i -w web`. Vite bundles the woff2 files, so no CDN request.
- `web/src/index.css`: `@import` the two font packages (latin subset files to keep size down); add `@theme { ... }` with
  - colours: `--color-paper` #f5efe2 (page), `--color-surface` #fffaf0 (the one card surface), `--color-line` #d8cdb9, `--color-ink` #17202a, `--color-ink-soft` #55706f, `--color-teal` #1e6964, `--color-teal-deep` #244a52, `--color-amber` #c97938, `--color-clay` #b95f4a (wrong), `--color-sage` #a8c8b4 (right). The final set comes from the hex inventory (most used first); rarely used one-offs get folded into the nearest token in T-003 to T-006, and contrast is fixed in T-007.
  - radii: `--radius-card`, `--radius-control`; fonts: `--font-sans` Inter Variable, `--font-display` Fraunces Variable.
  - base layer: body background is plain `var(--color-paper)` (grid and radial gradient removed), `color: var(--color-ink)`, `h1,h2,h3` use `--font-display`.
- Delete `web/tailwind.config.js`.
- No component edits here. Existing `bg-[#...]` classes still work, and are migrated per ticket.
- Not touched: `index.html` (the unpkg leaflet.css link goes in T-005), logo, quiz logic.

Test:

- `npm test` in the foreground, plus `npm run build` and `npm run lint`. Check that the built CSS in `dist` contains the font-face rules and the font files are emitted into `dist/assets`.
- Break check on a copy outside the repo: restore `tailwind.config.js` and the grid gradient, and confirm the test fails.
- Browser check (if the Chrome extension is reachable; otherwise recorded as not done): the font actually renders (computed font-family, document.fonts) and the page shows no grid.
